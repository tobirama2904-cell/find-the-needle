# Найди иголку — мобильный симулятор стога сена (Godot 4.7)

Как оригинальная *Find The Needle*, но на телефоне и с добавками:

- гора сена из **6 000 000 стеблей** (пирамида 28×28 м, MultiMesh — держит FPS на телефоне);
- **24 спрятанные иголки** внутри; металлоискатель пищит чаще, чем ближе иголка (и лампочка на нём краснеет);
- копание вручную (ЛКМ / кнопка КОПАТЬ), выносливость, перенос стеблей в руках, станция **SELL HAY**;
- магазин и техдерево: лопата, вилы, ведро, тачка, пылесос, детектор+, робо-рука, сила, выносливость, скорость рук, кроссовки, таблетка;
- **робо-рука** копает и продаёт сено сама — начало автоматизации;
- склад: рифлёные стены, крыша с щелями и солнечными снопами, пыль в воздухе, запертая дверь с сюжетом;
- сохранение прогресса, «Я узнаю этот день» — нет, это игра без этого. Престиж: собрал все иголки → новый стог ×1.6 и цена +25 %;
- русский интерфейс, мобильное управление (виртуальный стик + кнопки).

## Запуск на ПК
```
godot --path . 
```
или открыть папку в редакторе Godot 4.7.

## Сборка APK
Пуш в main запускает workflow `android-apk` (бесплатные раннеры GitHub) → артефакт `find-the-needle-apk`.

## Отладочные режимы (для разработки)
```
godot --headless --path . -- --sim            # проверка экономики и копания
godot --path . -- --shots /tmp/shots          # набор обзорных кадров
godot --path . -- --fresh                     # сброс прогресса
```
